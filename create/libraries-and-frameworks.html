Βιβλιοθήκες και Frameworks

Εισαγωγή Font Awesome

Font Awesome είναι μια δημοφιλής βιβλιοθήκη εικονιδίων που παρέχει μια ευρεία γκάμα εικονιδίων vector για χρήση σε ιστοσελίδες και εφαρμογές. Προσφέρει προσαρμοσμένα εικονίδια, τα οποία μπορούν να ενσωματωθούν εύκολα σε HTML, CSS και JavaScript.

<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/5.15.4/css/all.min.css">

Εισαγωγή Bootstrap 5.3.3

Bootstrap είναι ένα δημοφιλές front-end framework που διευκολύνει την ανάπτυξη responsive και mobile-first ιστοσελίδων.

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

Εισαγωγή Bootstrap Select

Bootstrap Select είναι μια βιβλιοθήκη που επεκτείνει την τυπική λειτουργικότητα των dropdowns που παρέχει το Bootstrap, προσθέτοντας περισσότερες δυνατότητες και βελτιώνοντας την εμπειρία του χρήστη. Επιτρέπει στους προγραμματιστές να ημιουργούν πιο προηγμένα και προσαρμοσμένα dropdown menus και select inputs, διατηρώντας παράλληλα την εμφάνιση του Bootstrap. 

<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/bootstrap-select/1.13.1/css/bootstrap-select.min.css">

Εισαγωγή Popper.js

Popper.js είναι μια JavaScript βιβλιοθήκη που χρησιμοποιείται για τη διαχείριση του positioning (θέσης) στοιχείων που "πετάγονται" (pop-up) στην οθόνη, όπως tooltips, dropdowns, popovers και modals. Παρέχει έναν αποτελεσματικό και αξιόπιστο τρόπο για να τοποθετήσεις αυτά τα στοιχεία σχεδόν σε οποιοδήποτε σημείο της σελίδας, διασφαλίζοντας ότι είναι σωστά τοποθετημένα σε σχέση με το στοιχείο αναφοράς. 

<script src="https://cdn.jsdelivr.net/npm/@popperjs/core@2.5.2/dist/umd/popper.min.js"></script>

Select2

Select2 είναι μια jQuery plugin που παρέχει μια βελτιωμένη και πιο ευέλικτη εμπειρία χρήστη για τη χρήση στοιχείων <select> σε φόρμες. Αυτή η βιβλιοθήκη προσφέρει πολλές δυνατότητες που δεν υπάρχουν στα τυπικά dropdowns του HTML, καθιστώντας τη ιδανική για περιπτώσεις που απαιτούν περισσότερες δυνατότητες επιλογής. 

<link href="https://cdnjs.cloudflare.com/ajax/libs/select2/4.0.13/css/select2.min.css" rel="stylesheet">
<script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/select2/4.0.13/js/select2.min.js"></script>
<script>
    $(document).ready(function() {
        $('#exampleSelect').select2({
            placeholder: "Επιλέξτε μια επιλογή",
            allowClear: true
        });
    });
</script>
