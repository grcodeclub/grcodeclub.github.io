SATA CableΧρησιμοποιείται για σύνδεση σκληρών δίσκων και SSD με τη μητρική πλακέτα.
HDMIΧρησιμοποιείται για τη σύνδεση οθονών και τηλεοράσεων, υποστηρίζει ήχο και εικόνα υψηλής ανάλυσης.
DVIΠαλιότερο καλώδιο που χρησιμοποιείται κυρίως για σύνδεση οθονών. Υπάρχουν τύποι DVI-D (μόνο ψηφιακό) και DVI-I (ψηφιακό και αναλογικό).
VGAΑναλογικό καλώδιο που χρησιμοποιείται για παλιότερες οθόνες.
Ethernet CableΧρησιμοποιείται για τη σύνδεση υπολογιστών σε τοπικά δίκτυα (LAN).

Thunderbolt CableΧρησιμοποιείται για τη σύνδεση υψηλής ταχύτητας περιφερειακών συσκευών και οθονών.
FireWire (IEEE 1394)Παλιότερη τεχνολογία που χρησιμοποιούνταν για τη σύνδεση εξωτερικών σκληρών δίσκων και άλλων συσκευών, έχει σχεδόν αντικατασταθεί από το USB.
CPU Cooler CableΧρησιμοποιείται για τη σύνδεση της ψύκτρας της CPU στη μητρική πλακέτα.
SAS CableΧρησιμοποιείται σε διακομιστές και αποθήκες για τη σύνδεση δίσκων με υψηλές ταχύτητες.
