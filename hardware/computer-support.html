Επίλυση Τεχνικών Προβλημάτων Υπολογιστή

  • Τροφοδοσία: Καλώδιο, πολύπριζο, διακόπτης PSU (I/0).
  • Σύνδεση front panel: Power SW/Reset SW στη μητρική.
  • Ελάχιστη διαμόρφωση: Μόνο CPU/RAM/PSU για test POST.
  • Δοκιμή με άλλο PSU αν υπάρχει υποψία βλάβης τροφοδοτικού.

Στόχος: Να αποκλείσεις ρεύμα/κουμπί πριν περάσεις σε hardware.

  • Καλώδιο/είσοδος οθόνης: HDMI/DP, σωστή πηγή.
  • Beep codes/LEDs POST από τη μητρική.
  • RAM: Ξανακάθισμα, δοκιμή ανά DIMM/slot.
  • GPU: Δοκιμή με iGPU ή άλλη κάρτα.
  • Clear CMOS και ελάχιστη διαμόρφωση.

  • Αποθήκευση: HDD → αναβάθμιση σε SSD.
  • Μνήμη: Λίγη RAM → προσθήκη/dual channel.
  • Λογισμικό: Πολλά startup apps, malware → καθαρισμός.
  • Θερμοκρασίες: Θερμικός περιορισμός → καθάρισμα/πάστα.
  • Drivers/Updates: Ενημέρωση chipset/GPU/OS.

  • Τροφοδοτικό (PSU): ανεπαρκές ή χαλασμένο → έλεγχος με άλλο PSU.
  • Υπερθέρμανση CPU/GPU: καθάρισμα ψυκτρών, αλλαγή πάστας, έλεγχος airflow.
  • Drivers/OS corruption: ενημέρωση drivers, Windows repair.
  • RAM errors: έλεγχος με MemTest86.

Εκκίνηση με βασικούς drivers/υπηρεσίες για troubleshooting.

  • Αφαίρεση προβληματικού driver/λογισμικού.
  • Σάρωση malware.
  • Έλεγχος εκκίνησης (clean boot).

Οι drivers είναι λογισμικό που επιτρέπει στο OS να επικοινωνεί με το hardware.

  • Χωρίς drivers: Ασυμβατότητες/αστάθεια.
  • Ενημέρωση: Διορθώσεις, ασφάλεια, επιδόσεις (π.χ. GPU).
  • Πηγές: Κατασκευαστής (chipset, GPU, LAN/Wi-Fi), Windows Update.
