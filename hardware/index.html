Υλικό υπολογιστών




ΚατηγορίαΌνομαΧρήση / Περιγραφή
ΚαλώδιοSATA CableΧρησιμοποιείται για σύνδεση σκληρών δίσκων και SSD με τη μητρική πλακέτα.
ΚαλώδιοHDMIΧρησιμοποιείται για τη σύνδεση οθονών και τηλεοράσεων, υποστηρίζει ήχο και εικόνα υψηλής ανάλυσης.
ΚαλώδιοDVIΠαλιότερο καλώδιο που χρησιμοποιείται κυρίως για σύνδεση οθονών. Υπάρχουν τύποι DVI-D (μόνο ψηφιακό) και DVI-I (ψηφιακό και αναλογικό).
ΚαλώδιοVGAΑναλογικό καλώδιο που χρησιμοποιείται για παλιότερες οθόνες.
ΚαλώδιοEthernet CableΧρησιμοποιείται για τη σύνδεση υπολογιστών σε τοπικά δίκτυα (LAN).
ΚαλώδιοUSBUSB Type-A, USB Type-Β ,USB Type-C, Micro USB, Mini USB
ΚαλώδιοThunderbolt CableΧρησιμοποιείται για τη σύνδεση υψηλής ταχύτητας περιφερειακών συσκευών και οθονών.
ΚαλώδιοFireWire (IEEE 1394)Παλιότερη τεχνολογία που χρησιμοποιούνταν για τη σύνδεση εξωτερικών σκληρών δίσκων και άλλων συσκευών, έχει σχεδόν αντικατασταθεί από το USB.
ΚαλώδιοCPU Cooler CableΧρησιμοποιείται για τη σύνδεση της ψύκτρας της CPU στη μητρική πλακέτα.
ΚαλώδιοSAS CableΧρησιμοποιείται σε διακομιστές και αποθήκες για τη σύνδεση δίσκων με υψηλές ταχύτητες.
ΚαλώδιοCharging CablesΚαλώδια που χρησιμοποιούνται για τη φόρτιση φορητών συσκευών όπως smartphones και tablets (συνήθως USB-C ή Micro USB)
