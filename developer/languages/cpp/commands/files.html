Αρχεία

Header: #include

Το #include <fstream> είναι ένα header αρχείο της C++ Standard Library που σου επιτρέπει να διαβάζεις και να γράφεις σε αρχεία (files).

#include <fstream>
ΚλάσηΧρήση
ifstreamΓια ανάγνωση από αρχεία (input file stream)
ofstreamΓια εγγραφή σε αρχεία (output file stream)
fstreamΓια ανάγνωση & εγγραφή ταυτόχρονα

Γραφή σε αρχείο (Write to file)

#include  <fstream>
using namespace std;

int main() {
    ofstream outFile("output.txt"); // Δημιουργεί ή αντικαθιστά αρχείο

    if (outFile.is_open()) {
        outFile << "GrCode Club!\n";
        outFile << "Αυτό είναι ένα αρχείο.\n";
        outFile.close(); // ΠΑΝΤΑ κλείσε το αρχείο
    } else {
        cout << "Δεν μπορώ να ανοίξω το αρχείο για εγγραφή.\n";
    }

    return 0;
}

Ανάγνωση από αρχείο (Read from file)

#include <fstream>
#include <iostream>
#include <string>
using namespace std;

int main() {
    ifstream inFile("output.txt"); // Άνοιγμα για ανάγνωση
    string line;

    if (inFile.is_open()) {
        while (getline(inFile, line)) {
            cout << line << endl;
        }
        inFile.close();
    } else {
        cout << "Δεν μπορώ να ανοίξω το αρχείο για ανάγνωση.\n";
    }

    return 0;
}

Προσθήκη (append) σε αρχείο

  1. ofstream outFile("output.txt", ios::app);
    • Δημιουργεί ένα αντικείμενο ofstream με όνομα outFile.
    • Ανοίγει το αρχείο output.txt σε λειτουργία προσθήκης (append).
    • Το flag ios::app σημαίνει:
      • Αν το αρχείο υπάρχει, θα προσθέσει περιεχόμενο στο τέλος του χωρίς να διαγράψει τα παλιά.
      • Αν δεν υπάρχει, το δημιουργεί.
ofstream outFile("output.txt", ios::app); // Άνοιγμα σε λειτουργία append
outFile << "Νέα γραμμή.\n";
outFile.close();

Έλεγχος ύπαρξης αρχείου

ifstream file("output.txt");
if (file.good()) {
    cout << "Το αρχείο υπάρχει.\n";
} else {
    cout << "Το αρχείο ΔΕΝ υπάρχει.\n";
}
file.close();

Συνδυασμός ανάγνωσης και εγγραφής

fstream file("data.txt", ios::in | ios::out | ios::app);
ios::inΑνάγνωση
ios::outΕγγραφή
ios::appΠροσθήκη στο τέλος
ios::truncΔιαγραφή περιεχομένου
ios::binaryΔυαδική λειτουργία

Διαχείριση αριθμών

  1. ofstream out("nums.txt");
    • Δημιουργεί ένα αντικείμενο ofstream με όνομα out.
    • Ανοίγει ή δημιουργεί το αρχείο nums.txt για εγγραφή (write).
    • Αν το αρχείο ήδη υπάρχει, διαγράφει το περιεχόμενό του και ξεκινά από την αρχή.
  2. out << 42 << " " << 3.14 << endl;
    • Γράφει στο nums.txt: 42 3.14
  3. out.close();
    • Κλείνει το αρχείο nums.txt
  4. ifstream in("nums.txt");
    • Δημιουργεί αντικείμενο ifstream με όνομα in.
    • Ανοίγει το αρχείο nums.txt για ανάγνωση.
  5. in >> a >> b;
    • Διαβάζει από το αρχείο nums.txt:
    • Το 42 μπαίνει στη a
    • Το 3.14 μπαίνει στη b
ofstream out("nums.txt");
out << 42 << " " << 3.14 << endl;
out.close();

ifstream in("nums.txt");
int a;
double b;
in >> a >> b;
cout << "a = " << a << ", b = " << b << endl;
in.close();

Έλεγχος αν άνοιξε σωστά το αρχείο

Πάντα να ελέγχεις αν το αρχείο άνοιξε επιτυχώς

ifstream file("data.txt");
if (!file) {
    cerr << "Σφάλμα: Δεν άνοιξε το αρχείο.\n";
    exit(1);
}
