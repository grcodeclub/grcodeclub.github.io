Η Python είναι μια γλώσσα προγραμματισμού υψηλού επιπέδου.

Η Python είναι μια υψηλού επιπέδου, ερμηνευόμενη γλώσσα προγραμματισμού που σχεδιάστηκε με σκοπό την απλότητα και την αναγνωσιμότητα.

  1. Η σύνταξη της Python είναι πολύ κοντά στην αγγλική γλώσσα, καθιστώντας την εύκολη στην κατανόηση και την εκμάθηση, ειδικά για αρχάριους.
  2. Διαθέτει μια εκτενή συλλογή βιβλιοθηκών και εργαλείων που διευκολύνουν την ανάπτυξη εφαρμογών σε διάφορους τομείς, όπως η ανάλυση δεδομένων, η μηχανική μάθηση, η ανάπτυξη ιστού, η επιστήμη δεδομένων, και πολλά άλλα.
  3. Η Python είναι συμβατή με πολλές πλατφόρμες και μπορεί να τρέξει σε Windows, macOS και Linux.
  4. Η καθαρή και αναγνωρίσιμη σύνταξη διευκολύνει την αναβάθμιση και την συντήρηση των προγραμμάτων που έχουν γραφτεί σε Python.
  5. Η κοινότητα της Python είναι μεγάλη και ενεργή,

Τύποι δεδομένων

Για να χρησιμοποιήσουμε μια μεταβλητή, χρειαζόμαστε να της δώσουμε ένα όνομα και στην συνέχεια να της εκχωρήσουμε κάποια τιμή. Με το σύμβολο = δίνουμε μια τι στην μεταβλητή.
Για παράδειγμα 

x=15

Προσοχή, δεν δηλώνουμε τον τύπο δεδομένων που θα έχει η μεταβλητή, όπως κάνουμε σε άλλες γλώσσες προγραμματισμού όπως η C.

Στην Python οι τύποι δεδομένων είναι:

  • οι αριθμοί: int , float , complex (μιγαδικοί αριθμοί)
  • Συμβολοσειρές: str
  • Ο λογικός τύπος: bool (έχει 2 τιμές true και false)

Έξοδος (Output)

print() Χρησιμοποιείται για να εμφανίσει δεδομένα στην κονσόλα.

print("GrCode Club")

Μπορείς να εμφανίσεις πολλαπλές τιμές ή μεταβλητές με διαχωρισμό από κόμμα:

name = "Νίκος"
age = 25
print("Το όνομα μου είναι", name, "και είμαι", age, "χρονών.")

Είσοδος (Input)

Η είσοδος από το χρήστη γίνεται κυρίως με τη χρήση με την εντολή input()

input(): Χρησιμοποιείται για να λαμβάνεις δεδομένα από τον χρήστη με τη μορφή κειμένου (string).

name = input("Ποιο είναι το όνομά σου; ")
print("Γειά σου, " + name)

Η τιμή που επιστρέφεται από την input() είναι πάντα string, οπότε αν χρειαστείς κάποια άλλη μορφή (π.χ., αριθμό), θα πρέπει να τη μετατρέψεις:

age = int(input("Πόσο χρονών είσαι; "))
print("Είσαι " + str(age) + " χρονών.")

Δομή ελέγχου

οι δομές ελέγχου χρησιμοποιούνται για τη λήψη αποφάσεων μέσα σε ένα πρόγραμμα. Αυτές οι δομές επιτρέπουν τον έλεγχο της ροής του προγράμματος, ανάλογα με το αν οι συνθήκες είναι αληθείς ή ψευδείς.
Οι δομές ελέγχου είναι:

1) if: Ελέγχει μια συνθήκη και εκτελεί έναν κώδικα αν η συνθήκη είναι αληθής.

x = 10
if x > 5:
    print("Το x είναι μεγαλύτερο από 5")

2) else: Εκτελεί έναν κώδικα αν η συνθήκη στο if ή στο elseif (αν υπάρχει) είναι ψευδή.

x = 3
if x > 5:
    print("Το x είναι μεγαλύτερο από 5")
else:
    print("Το x είναι μικρότερο ή ίσο με 5")

3) elif: Προσθέτει επιπλέον συνθήκες ελέγχου σε μια δήλωση if.

x = 7
if x > 10:
    print("Το x είναι μεγαλύτερο από 10")
elif x == 7:
    print("Το x είναι ίσο με 7")
else:
    print("Το x είναι μικρότερο από 10 αλλά δεν είναι 7")

For

Η for επανάληψη χρησιμοποιείται για να επαναλάβεις κώδικα για κάθε στοιχείο μιας ακολουθίας.

Χρήση range() με το for loop. Η συνάρτηση range() δημιουργεί ακολουθίες αριθμών

# Εκτύπωση αριθμών από 0 έως 4
for i in range(5):
    print(i)

Το range() μπορεί επίσης να δεχτεί αρχική τιμή, τελική τιμή, και βήμα:

# Εκτύπωση ζυγών αριθμών από 2 έως 10
for i in range(2, 11, 2):
    print(i)

while επανάληψη

Η while επανάληψη εκτελεί τον κώδικα όσο η συνθήκη που ελέγχεται είναι αληθής. Αν η συνθήκη γίνει ψευδής, η επανάληψη σταματά.

# Εκτύπωση αριθμών από 1 έως 5
i = 1
while i <= 5:
    print(i)
    i = i + 1

Χρήση του break και continue

Η εντολή break χρησιμοποιείται για να διακόψει την επανάληψη και να βγει από το loop πριν η συνθήκη γίνει ψευδής.

for i in range(10):
    if i == 5:
        break  # Διακοπή όταν i είναι 5
    print(i)

Η εντολή continue χρησιμοποιείται για να παραλείψει το υπόλοιπο των εντολών μέσα στο loop και να προχωρήσει στην επόμενη επανάληψη.

for i in range(5):
    if i == 3:
        continue  # Παράλειψη όταν i είναι 3
    print(i)
