Συναρτήσεις

Οι συναρτήσεις στην Python είναι κομμάτια κώδικα που επιτρέπουν την οργάνωση, επαναχρησιμοποίηση και τμηματοποίηση του προγράμματος. Μια συνάρτηση εκτελεί ένα σύνολο εντολών όταν καλείται και μπορεί να δεχθεί παραμέτρους και να επιστρέψει αποτελέσματα.

Δημιουργία συνάρτησης

Για να δημιουργήσεις μια συνάρτηση στην Python, χρησιμοποιείς τη λέξη-κλειδί def. Μια συνάρτηση μπορεί να περιέχει παραμέτρους και μπορεί να επιστρέφει μια τιμή με τη χρήση της return.

def add_numbers(a, b):
    return a + b
result = add_numbers(5, 3)
print(result)
