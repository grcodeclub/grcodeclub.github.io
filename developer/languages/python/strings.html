Python - Συμβολοσειρές

Δες παραδείγματα στο GitHub

Η μέθοδος capitalize() κάνει το πρώτο γράμμα του string.

text = "grCode club"
print(text.capitalize())  # Εκτύπωση: GrCode club

Η μέθοδο title() κάνει capitalize κάθε πρώτο γράμμα κάθε λέξης στο string.

text = "grCode club"
print(text.title())  # Εκτύπωση: GrCode Club

Η μέθοδος upper() επιστρέφει τη συμβολοσειρά με κεφαλαία γράμματα.

text = "GrCode Club"
print(text.upper()) #Εκτύπωση 'GRCODE CLUB'

Η μέθοδος lower() επιστρέφει τη συμβολοσειρά με πεζά γράμματα.

text = "GrCode Club"
print(text.lower()) #Εκτύπωση 'grcode club'

Η μέθοδος strip() αφαιρεί οποιοδήποτε κενό διάστημα από την αρχή ή το τέλος.

text= "GrCode Club"
print(text.strip()) #Εκτύπωση 'GrCode Club'

Η μέθοδος swapcase() αλλάζει τα πεζά σε κεφαλαία και το αντίστροφο σε κάθε γράμμα του string.

text= "GrCode Club"
print(text.swapcase())  # Εκτύπωση: gRcODE cLUB

Ελέγξτε μια συμβολοσειρά

Για να ελέγξουμε εάν μια συγκεκριμένη φράση ή χαρακτήρας υπάρχει σε μια συμβολοσειρά, μπορούμε να χρησιμοποιήσουμε τη λέξη-κλειδί in.

text = "GrCode Club"
print("Gr" in text) #Εκτύπωση True

Για να ελέγξουμε αν μια συγκεκριμένη φράση ή χαρακτήρας ΔΕΝ υπάρχει σε μια συμβολοσειρά, μπορούμε να χρησιμοποιήσουμε τη λέξη-κλειδί not in.

text = "GrCode Club"
print("Hello" not in text) #Εκτύπωση True

f-strings

Τι είναι τα f-strings;
Τα f-strings (ή formatted string literals) εισήχθησαν στην Python 3.6 και αποτελούν έναν γρήγορο και εύκολο τρόπο για την εισαγωγή μεταβλητών και εκφράσεων μέσα σε μια συμβολοσειρά. Τα f-strings ξεκινούν με το πρόθεμα f και επιτρέπουν την ενσωμάτωση μεταβλητών και εκφράσεων μέσα σε αγκύλες {}.

site = "GrCode Club"
greeting = f"Καλώς ήρθατε στο {site}!"
print(greeting)

Μορφοποίηση Αριθμών

1) Δεκαδικά ψηφία:

pi = 3.14159
formatted = f"Το π είναι περίπου ίσο με {pi:.2f}."
print(formatted)  # Το π είναι περίπου ίσο με 3.14.

2) Αριθμοί με διαχωριστικά χιλιάδων:

population = 123456789
formatted = f"Ο πληθυσμός είναι {population:,}."
print(formatted)  # Ο πληθυσμός είναι 123,456,789.

3) Εκθετική μορφή:

value = 0.00001234
formatted = f"Η τιμή είναι {value:.2e}."
print(formatted)  # Η τιμή είναι 1.23e-05.

Μορφοποίηση Συμβολοσειρών

Μπορείτε να ευθυγραμμίσετε τις συμβολοσειρές μέσα από τα f-strings:

name = "Μαρία"
formatted = f"|{name:<10}|{name:^10}|{name:>10}|"
print(formatted)  # |Μαρία     |   Μαρία   |     Μαρία|

  1. < : Ευθυγράμμιση αριστερά.
  2. ^ : Κεντράρισμα.
  3. > : Ευθυγράμμιση δεξιά.
