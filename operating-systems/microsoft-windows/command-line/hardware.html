Εντολές για το Hardware

Λίστα όλων των drives

fsutil fsinfo drives

Ανοίγει System Information GUI με όλα τα hardware resources

msinfo32

Πληροφορίες για κάρτες δικτύου

wmic nic get name, MACAddress, Speed

Πληροφορίες BIOS/UEFI

wmic bios get smbiosbiosversion,serialnumber,manufacturer

Ανοίγει το παράθυρο Disk Management, όπου μπορείτε να διαχειριστείτε τους δίσκους, τις κατατμήσεις και τους τόμους του συστήματος. Μπορείτε να δημιουργήσετε, να διαγράψετε, να αντιγράψετε, να μεταβάλετε το μέγεθος και να διαμορφώσετε τις κατατμήσεις.

diskmgmt.msc

RAM

Πληροφορίες για RAM

wmic memorychip get capacity, speed, manufacturer

Πληροφορίες RAM με τύπο και θέση

wmic memorychip get devicelocator, capacity, speed, memorytype

CPU

Πληροφορίες για CPU

wmic cpu get name,NumberOfCores,NumberOfLogicalProcessors

Ποσοστό τρέχοντος φορτίου CPU

wmic cpu get loadpercentage

Μέγιστη και τρέχουσα ταχύτητα CPU

wmic cpu get maxclockspeed,currentclockspeed

Σκληρό Δίσκο

Ελέγχει την κατάσταση του σκληρού δίσκου και επιδιορθώνει τυχόν σφάλματα αρχείων.

chkdsk

Εκτελεί τον εργαλείο αποκατάστασης συστήματος αρχείων (Disk Defragmenter) για τη βελτιστοποίηση της τοποθέτησης των αρχείων στον σκληρό δίσκο.

defrag

Εκκινεί το DiskPart, ένα εργαλείο γραμμής εντολών που σας επιτρέπει να διαχειρίζεστε τους σκληρούς δίσκους, τις κατατμήσεις και τους τόμους. Μπορείτε να δημιουργήσετε, να διαγράψετε, να μεταβάλετε το μέγεθος και να διαμορφώσετε κατατμήσεις.

diskpart

Πληροφορίες για δίσκους / SSD

wmic diskdrive get model,size,serialnumber

Τύπος δίσκου (HDD/SSD/USB) και σύνδεση

wmic diskdrive get model,serialnumber,interfacetype,mediatype

Διαθέσιμος χώρος δίσκου

fsutil volume diskfree C:

Εμφάνιση όλων των δίσκων και partitions

wmic logicaldisk get name,description

Εμφάνιση όλων των φυσικών δίσκων

wmic diskdrive list brief
