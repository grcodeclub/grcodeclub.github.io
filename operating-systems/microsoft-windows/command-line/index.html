Command Line

Το Command Line (γραμμή εντολών) είναι μια διεπαφή χρήστη που επιτρέπει την επικοινωνία με το λειτουργικό σύστημα μέσω γραπτών εντολών αντί για γραφικό περιβάλλον (GUI).

    Πώς ανοίγεις το Command Prompt (cmd) και να μεταβείς στο C:\Windows\System32 ως διαχειριστής

    • Μέσω Start (πιο απλό)
      1. Πάτα το πλήκτρο Win
      2. Πληκτρολόγησε cmd
      3. Στα αποτελέσματα, κάνε δεξί κλικ → Run as administrator (Εκτέλεση ως διαχειριστής).
    • Μέσω συντόμευσης (Win+R και Ctrl+Shift+Enter)
      1. Πάτα Win + R για το παράθυρο Run
      2. Πληκτρολόγησε cmd
      3. Πίεσε Ctrl + Shift + Enter — αυτό ξεκινά το cmd με δικαιώματα διαχειριστή
