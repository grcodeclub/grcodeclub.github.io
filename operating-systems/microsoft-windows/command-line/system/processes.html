Εντολές Διαχείριση Διεργασιών

Εμφανίζει τη λίστα των εκτελούμενων διεργασιών στο σύστημα, μαζί με λεπτομέρειες όπως το ID διεργασίας, την κατάσταση και την κατανάλωση πόρων.

tasklist

Εμφανίζει όλες τις διεργασίες με επιπλέον πληροφορίες (window title, session).

tasklist /v

Φιλτράρει και εμφανίζει μόνο διεργασίες με συγκεκριμένο όνομα

tasklist /fi "imagename eq chrome.exe"

Φιλτράρισμα διεργασιών με βάση κατάσταση

tasklist /fi "STATUS eq NOT RESPONDING"

Δείξε τις διεργασίες μαζί με τις υπηρεσίες που τις τρέχουν

tasklist /svc

Εμφάνιση διεργασιών από συγκεκριμένη session

tasklist /FI "SESSION eq 1"

Διεργασίες που τρέχουν από συγκεκριμένο user

tasklist /FI "USERNAME eq MyUser"

Τερματισμός διεργασίας με PID

taskkill /PID 1234

Τερματισμός διεργασίας με όνομα (force)

taskkill /IM chrome.exe /F

Τερματισμός όλων των διεργασιών που δεν απαντούν

taskkill /FI "STATUS eq NOT RESPONDING" /F

Τερματισμός όλων των διεργασιών από συγκεκριμένη session

taskkill /FI "SESSION eq 1" /F

Τερματισμός όλων των διεργασιών από συγκεκριμένο user

taskkill /FI "USERNAME eq MyUser" /F

Τερματισμός διεργασιών με wildcard

taskkill /IM "chrome*" /F

Ανοίγει το παράθυρο Services, όπου μπορείτε να διαχειριστείτε τις υπηρεσίες που εκτελούνται στον υπολογιστή σας. Μπορείτε να ενεργοποιήσετε, απενεργοποιήσετε ή αλλάξετε τις ρυθμίσεις των υπηρεσιών.

services.msc

Εκτελεί το Windows Management Instrumentation Command-line (WMIC) και παρέχει προηγμένες λειτουργίες διαχείρισης των διεργασιών, όπως η εμφάνιση λεπτομερών πληροφοριών και η διαχείριση των προτεραιοτήτων των διεργασιών.

wmic process

Λίστα διεργασιών με PID και memory usage

wmic process get ProcessId,Name,WorkingSetSize

Λίστα διεργασιών με περισσότερα πεδία (CPU, Threads, Priority)

wmic process get ProcessId,Name,ThreadCount,Priority,ExecutablePath

Τερματισμός διεργασίας με WMIC

wmic process where "name='notepad.exe'" delete

Φιλτράρισμα διεργασιών με συγκεκριμένο χρήστη

wmic process where "name='chrome.exe' and sessionid=1" get ProcessId,Name

Λίστα διεργασιών που χρησιμοποιούν συγκεκριμένο executable path

wmic process where "ExecutablePath='C:\\Program Files\\App\\app.exe'" get Name, ProcessId

Λίστα υπηρεσιών και κατάστασή τους

net start

Σταμάτημα υπηρεσίας

net stop "ServiceName"

Εκκίνηση υπηρεσίας

net start "ServiceName"
