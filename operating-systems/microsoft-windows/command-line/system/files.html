Διαχείριση Αρχείων και Φακέλων

Εμφανίζει τα περιεχόμενα του τρέχοντος φακέλου

diskmgmt.msc

Αλλαγή φακέλου

cd C:\User

Επιστροφή στον προηγούμενο φάκελο

cd ..

Δημιουργεί νέο φάκελο

mkdir [όνομα]

Διαγράφει φάκελο (πρέπει να είναι άδειος)

rmdir [όνομα]

Διαγράφει αρχεία

del [όνομα]

Αντιγράφει αρχεία

copy [αρχείο] [προορισμός]

Αντιγράφει φακέλους και υποφακέλους

xcopy [πηγή] [προορισμός] /s /e

Μετακινεί αρχεία

move [αρχείο] [προορισμός]

Μετονομασία αρχείων ή φακέλων

ren [παλιό] [νέο]

Δείχνει/αλλάζει χαρακτηριστικά αρχείου

attrib [αρχείο]
