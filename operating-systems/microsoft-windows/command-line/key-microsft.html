Εντολές Ενεργοποίησης Windows

Εμφανίζει βασικές πληροφορίες για την ενεργοποίηση (έκδοση, τύπος καναλιού π.χ. Retail/OEM/Volume).

slmgr /dli

Εμφανίζει αναλυτικές πληροφορίες για την άδεια (κανάλι, ημερομηνία ενεργοποίησης, κλειδί, activation ID).

slmgr /dlv

Δείχνει αν τα Windows είναι μόνιμα ενεργοποιημένα ή αν λήγουν (π.χ. σε δοκιμαστικές εκδόσεις).

slmgr /xpr

Εγκαθιστά νέο κλειδί

slmgr /ipk XXXXX-XXXXX-XXXXX-XXXXX-XXXXX

Ενεργοποιεί τα Windows online (αφού έχεις εισαγάγει το κλειδί).

slmgr /ato

Απεγκαθιστά το τρέχον κλειδί προϊόντος (χρήσιμο πριν το μεταφέρεις σε άλλο PC).

slmgr /upk

Διαγράφει το κλειδί από το μητρώο (Registry) για λόγους ασφάλειας.

slmgr /cpky

Ορίζει KMS server για ενεργοποίηση μέσω εταιρικού δικτύου.

slmgr /skms [όνομα_διακομιστή]

Καταργεί τον KMS server και επαναφέρει την προεπιλογή.

slmgr /ckms

Ενεργοποιεί συγκεκριμένη άδεια (αν υπάρχουν πολλές).

slmgr /ato [activation ID]
