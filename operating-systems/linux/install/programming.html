Εγκατάσταση γλώσσες προγραμματισμού

Python 3

sudo apt install python3

Gcc

sudo apt install gcc

G++

sudo apt install g++

Nodejs (Node.js)

sudo apt install nodejs

Php

  1. Php: Εγκαθιστά την κύρια έκδοση της PHP που είναι διαθέσιμη στα αποθετήρια του λειτουργικού συστήματος.
  2. libapache2-mod-php: Προσθέτει τη δυνατότητα στον Apache να "καταλαβαίνει" και να εκτελεί PHP scripts.
  3. php-mysql: Εγκαθιστά τη βιβλιοθήκη PHP που επιτρέπει τη σύνδεση της PHP με βάσεις δεδομένων MySQL ή MariaDB.
sudo apt install php libapache2-mod-php php-mysql
