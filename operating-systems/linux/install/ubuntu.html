Eγκατάσταση Linux

Προετοιμασία USB για εγκατάσταση

  1. Κατέβασε το ISO αρχείο του distro από την επίσημη σελ
  2. Δημιούργησε ένα bootable USB
    • Windows: Χρησιμοποίησε Rufus ή Balena Etcher
    • Linux: dd ή Etcher
    • Mac: Etcher
Χρειάζεσαι USB με τουλάχιστον 4GB.

Επανεκκίνηση και Boot από USB

  1. Τοποθέτησε το USB στον υπολογιστή.
  2. Κάνε επανεκκίνηση και μπες στο BIOS/UEFI (συνήθως πατώντας F2, F12 κατά την εκκίνηση)
  3. Επίλεξε το USB ως πρώτη συσκευή εκκίνησης
  4. Αποθήκευσε και κάνε επανεκκίνηση
Αν δεν βλέπεις το USB, έλεγξε αν είναι ενεργοποιημένο το UEFI/Legacy Boot ανάλογα με το partition scheme που επέλεξες.

Δοκιμή ή εγκατάσταση (Live Mode)

  • Μπορείς να τρέξεις το Linux απευθείας από το USB χωρίς να επηρεάσεις τα αρχεία σου.
  • Ιδανικό για να δεις αν αναγνωρίζονται όλα τα εξαρτήματα (Wi-Fi, ήχος, οθόνη κ.λπ.)
Συνιστώ πρώτα Try Ubuntu, ειδικά για νέο hardware.

Εκκίνηση Εγκατάστασης

  1. Εκκίνηση εγκατάστασης από το Live USB
  2. Επιλογή γλώσσας (π.χ. Ελληνικά ή Αγγλικά).
  3. Επιλογή διάταξης πληκτρολογίου.
  4. Επιλογή Normal ή Minimal installation:
    • Normal => Έρχεται με browser, office, media player.
    • Minimal => Μόνο βασικά εργαλεία.

Επιλογή τύπου εγκατάστασης

  1. Erase disk and install Ubuntu: Διαγράφει όλα τα δεδομένα στο δίσκο. (ροσοχή: δεν μπορεί να ανακτηθεί τίποτα.)
  2. Install Ubuntu alongside Windows: Δημιουργεί dual boot. Μπορείς να επιλέγεις ανάμεσα σε Windows και Ubuntu κατά την εκκίνηση.
  3. Something else (προχωρημένο) - Μπορείς να δημιουργήσεις custom partitions:
    • / (root) => τοποθετείται το σύστημα, συνήθως 20–50 GB
    • /home => προσωπικά αρχεία
    • swap => swap area (συνήθως ίση με τη RAM, ή λιγότερο αν έχεις πολύ RAM)

Ρύθμιση διαμερισμάτων (προχωρημένο)

Αν επιλέξεις Something else

  1. Δημιουργία root partition:
    • Type: Ext4
    • Mount point: /
    • Size: τουλάχιστον 20GB
  2. Δημιουργία swap partition:
    • Size: ίσο ή μικρότερο της RAM
    • Type: swap
  3. Δημιουργία home partition:
    • Mount point: /home
    • Type: Ext4
    • Size: υπόλοιπος χώρος δίσκου
Αν θέλεις dual boot με Windows, μην αγγίξεις τα Windows partitions!

Επιλογή ζώνης ώρας

Άφησε το Ubuntu να εντοπίσει την ζώνη ώρας ή επίλεξε χειροκίνητα.

Δημιουργία χρήστη

  1. Όνομα χρήστη
  2. Κωδικός πρόσβασης
  3. Όνομα υπολογιστή
  4. Επιλογή “Log in automatically” ή “Require password to log in”

Εκκίνηση εγκατάστασης

  • Κλικ στο Install Now
  • Το σύστημα θα ξεκινήσει την αντιγραφή αρχείων
  • Συνήθως χρειάζεται 10–30 λεπτά, ανάλογα με το hardware
  • Μετά την ολοκλήρωση, θα εμφανιστεί μήνυμα: Restart Now.
