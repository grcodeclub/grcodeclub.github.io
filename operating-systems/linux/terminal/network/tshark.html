Καταγραφή (Capture) με tshark

Εμφανίζει όλα τα διαθέσιμα network interfaces

tshark -D

Καταγράφει πακέτα στο interface eth0

sudo tshark -i eth0

Συλλέγει 100 πακέτα από το Wi-Fi

sudo tshark -i wlan0 -c 100

Αποθηκεύει την καταγραφή σε αρχείο

sudo tshark -i eth0 -w test.pcap

Διαβάζει και εμφανίζει υπάρχουσα καταγραφή

tshark -r capture.pcap

Συλλέγει μόνο πακέτα προς/από 8.8.8.8

tshark -f "host 8.8.8.8"

Καταγράφει μόνο HTTP κίνηση

tshark -f "port 80"

Μόνο TCP πακέτα

tshark -f "tcp"

Μόνο UDP πακέτα

tshark -f "udp"

Μόνο πακέτα του συγκεκριμένου υποδικτύου

tshark -f "net 192.168.1.0/24"
