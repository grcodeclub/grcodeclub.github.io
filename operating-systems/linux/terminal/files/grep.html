Grep

Το grep (Global Regular Expression Print) ψάχνει γραμμές κειμένου που ταιριάζουν σε μοτίβο (pattern) μέσα σε αρχεία ή την έξοδο άλλων εντολών.

Χρησιμοποιώντας την παρακάτω εντολή θα μας εμφανίσει όλες τις γραμμές του αρχείου file.txt που περιέχουν την λέξη grcodeclub.

grep grcodeclub file.txt

Αναζήτηση της λέξης grcodeclub σε πολλά αρχεία.

grep "grcodeclub" file1 file2

Αγνοεί πεζά/κεφαλαία

grep -i "grcodeclub" file.txt

Εμφανίζει αριθμό γραμμής

grep -n "grcodeclub" file.txt

Εξαιρεί γραμμές που περιέχουν το pattern

grep -v "grcodeclub" file.txt

Εμφανίζει πόσες φορές βρέθηκε

grep -c "grcodeclub" file.txt

Δείχνει μόνο ποια αρχεία περιέχουν το pattern

grep -l "grcodeclub" *.log

Αντίστροφο: αρχεία που δεν περιέχουν το pattern

grep -L "grcodeclub" *.log

Ψάχνει αναδρομικά σε όλους τους υποφακέλους

grep -r "grcodeclub" /path

Αναζήτηση μόνο σε αρχεία με συγκεκριμένη κατάληξη

grep -R --include="*.py" "import" /home

Εξαιρεί συγκεκριμένα αρχεία

grep -R --exclude="*.log" "error" /var/log

Εμφανίζει το pattern με χρώμα

grep --color=auto "grcodeclub" file

Εμφανίζει και το όνομα του αρχείου μπροστά από κάθε αποτέλεσμα

grep -H "grcodeclub" file

Εμφανίζει μόνο το τμήμα που ταιριάζει (όχι ολόκληρη γραμμή)

grep -o "pattern" file

Πίνακας Κανονικών Εκφράσεων (Regex) για grep

grep "^root" /etc/passwdΤαιριάζει γραμμές που ξεκινούν με το "root".
grep "bash$" /etc/passwdΤαιριάζει γραμμές που τελειώνουν με το "bash".
grep "r..t" fileΑντιπροσωπεύει οποιονδήποτε χαρακτήρα (εκτός από newline).
grep "lo*l" fileΕπαναλαμβάνει 0 ή περισσότερες φορές τον προηγούμενο χαρακτήρα ή μοτίβο.
grep "lo+l" fileΕπαναλαμβάνει 1 ή περισσότερες φορές τον προηγούμενο χαρακτήρα ή μοτίβο.
grep "colou?r" fileΟ προηγούμενος χαρακτήρας είναι προαιρετικός (0 ή 1 φορά).
grep "[ch]at" fileΤαιριάζει οποιονδήποτε από τους χαρακτήρες μέσα στις αγκύλες (a, b ή c).
grep "[^a-z]" fileΤαιριάζει οποιονδήποτε χαρακτήρα εκτός από τους a, b ή c.
grep "[a-z]" fileΤαιριάζει οποιονδήποτε πεζό χαρακτήρα από a έως z.
grep "[0-9]" fileΤαιριάζει οποιονδήποτε αριθμό από 0 έως 9.
grep "\\." fileΧρησιμοποιείται για να “ξεφύγεις” ειδικούς χαρακτήρες, π.χ. για να ψάξεις τελεία.
grep -E "cat|dog" fileΉ (OR): ταιριάζει είτε το πρώτο είτε το δεύτερο μοτίβο.
grep -E "(foo|bar)" fileΟμαδοποιεί εκφράσεις για χρήση με τελεστές όπως + ή *.
grep -E "a{2,4}" fileΟ προηγούμενος χαρακτήρας επαναλαμβάνεται από n έως m φορές.
