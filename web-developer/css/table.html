Πίνακες

Οι πίνακες χρησιμοποιούνται για την οργάνωση δεδομένων σε γραμμές και στήλες. Με το CSS, μπορούμε να βελτιώσουμε την εμφάνιση και τη λειτουργικότητά τους.

Βασική Μορφοποίηση με CSS

table {
  width: 100%;
  border-collapse: collapse; /* Ενώνει τα περιγράμματα */
}

th, td {
  border: 1px solid #ddd; /* Προσθέτει περίγραμμα */
  padding: 10px; /* Καλύτερη εμφάνιση κελιών */
  text-align: left;
}

th {
  background-color: #f4f4f4; /* Φόντο κεφαλίδας */
  font-weight: bold;
}

Εναλλάξ Χρώματα Σειρών

Αυτός ο κώδικας CSS χρησιμοποιεί την ψευδοκλάση nth-child() για να εφαρμόσει διαφορετικά χρώματα στις σειρές () ενός πίνακα, δημιουργώντας το εφέ ζέβρας (zebra striping). Ας αναλύσουμε πώς λειτουργεί:

  • Η ψευδοκλάση nth-child(n) επιλέγει τα στοιχεία που είναι nth παιδιά του γονέα τους.
  • Στην περίπτωση του tr:nth-child(odd), επιλέγονται οι περιττές (odd) σειρές: 1η, 3η, 5η, κ.λπ.
  • Στην περίπτωση του tr:nth-child(even), επιλέγονται οι άρτιες (even) σειρές: 2η, 4η, 6η, κ.λπ.
tbody tr:nth-child(odd) {
  background-color: #f9f9f9; /* Ανοιχτό γκρι */
}

tbody tr:nth-child(even) {
  background-color: #e9e9e9; /* Λίγο πιο σκούρο */
}

Στρογγυλεμένες Γωνίες & Σκιά

table {
  border-radius: 8px;
  overflow: hidden;
  box-shadow: 0px 4px 8px rgba(0, 0, 0, 0.2);
}

Responsive Πίνακες (Για Κινητά & Μικρές Οθόνες)

Αν ο πίνακάς μας έχει πολλές στήλες, μπορεί να μην χωράει σε μικρές οθόνες. Χρησιμοποιούμε overflow-x: auto; για να προσθέσουμε οριζόντια κύλιση όταν χρειάζεται.

@media screen and (max-width: 600px) {
  table {
    width: 100%;
    display: block;
    overflow-x: auto;
  }
}
