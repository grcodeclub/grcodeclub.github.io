Link

Βασική Σύνταξη

a:link { color: blue; }      /* Αρχικό χρώμα για τα links */
a:visited { color: purple; }  /* Χρώμα όταν έχει ήδη γίνει κλικ */
a:hover { color: red; }       /* Χρώμα όταν ο χρήστης περνά το ποντίκι πάνω από το link */
a:active { color: orange; }   /* Χρώμα όταν γίνεται κλικ */

Αφαίρεση Υπογράμμισης από τα Links

Από προεπιλογή, τα links έχουν υπογράμμιση. Μπορούμε να την αφαιρέσουμε με:

a {text-decoration: none;}

Αλλαγή Στυλ κατά το Hover

a:hover {
  color: red;
  text-decoration: underline;
}

Button Style Links

Για να κάνουμε ένα link να μοιάζει με κουμπί:

a.button {
  display: inline-block;
  padding: 10px 20px;
  background-color: #007bff;
  color: white;
  text-decoration: none;
  border-radius: 5px;
}

a.button:hover {
  background-color: #0056b3;
}

Παράδειγμα HTML:

<a href="https://grcodeclub.gr" class="button">Click Me</a>

Δημιουργία Εφέ Hover με Μεταβάσεις

Για να κάνουμε ένα link να αλλάζει σταδιακά χρώμα:

a {
  color: blue;
  transition: color 0.3s ease-in-out;
}

a:hover {
  color: red;
}
