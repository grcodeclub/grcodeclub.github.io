Class Bootstrap

Το Bootstrap είναι ένα από τα πιο διαδεδομένα frameworks για την ανάπτυξη responsive ιστοσελίδων. Παρέχει έτοιμες κλάσεις για layout, φόρμες, κουμπιά, πίνακες, εικόνες και πολλά ακόμη στοιχεία, ώστε να μπορείς να δημιουργήσεις μοντέρνες και καλαίσθητες σελίδες χωρίς να γράψεις πολύ custom CSS.
Στον παρακάτω οδηγό συγκεντρώνουμε τις βασικές κατηγορίες κλάσεων του Bootstrap, με περιγραφή και παραδείγματα χρήσης.

    Components

    Οι κλάσεις αυτής της κατηγορίας σχετίζονται με τη δομή της σελίδας. Χρησιμοποιούνται για να οργανώνεις το περιεχόμενο σε containers, rows και columns, δηλαδή το γνωστό grid system του Bootstrap. Με αυτές φτιάχνεις το βασικό “σκελετό” της σελίδας.

    Forms

    Κλάσεις για την μορφοποίηση φορμών.

    Utilities

    Οι utility classes είναι μικρές, έτοιμες κλάσεις που σε βοηθούν να κάνεις γρήγορο styling χωρίς να γράψεις CSS. Εδώ ανήκουν χρώματα, backgrounds, borders, text alignment, display, shadows κλπ. Σου λύνουν τα χέρια για μικρο-ρυθμίσεις.

    Flexbox

    Οι κλάσεις Flexbox χρησιμοποιούνται για στοίχιση και διάταξη στοιχείων με το CSS Flexbox model. Επιτρέπουν εύκολη τοποθέτηση σε γραμμές/στήλες, στοίχιση στο κέντρο, κατανομή χώρου και responsive layouts.

    Utilities

    Οι utility classes είναι μικρές, έτοιμες κλάσεις που σε βοηθούν να κάνεις γρήγορο styling χωρίς να γράψεις CSS. Εδώ ανήκουν χρώματα, backgrounds, borders, text alignment, display, shadows κλπ. Σου λύνουν τα χέρια για μικρο-ρυθμίσεις.

    Spacing

    Οι κλάσεις sizing σου επιτρέπουν να ορίσεις διαστάσεις σε ποσοστά ή viewport units. Π.χ. w-100 γεμίζει το πλάτος, h-50 το μισό ύψος, vh-100 γεμίζει το viewport. Χρησιμοποιούνται όταν χρειάζεσαι responsive ύψος/πλάτος.

    Typography

    Αφορά την εμφάνιση του κειμένου: γραμματοσειρές, μεγέθη επικεφαλίδων, line-height, έντονα/πλάγια, στοίχιση, κεφαλαία/πεζά, χρώματα, truncation κλπ. Είναι βασικό κομμάτι του Bootstrap για να δίνεις σωστή μορφή στο περιεχόμενο.

    Tables

    Κλάσεις για τη μορφοποίηση πινάκων. Σου δίνουν στυλ όπως borders, striped rows, hover effects, responsive tables και alignment σε κελιά. Κάνουν τους πίνακες πιο καθαρούς και προσαρμοστικούς.

    Images

    Κλάσεις για να κάνεις τις εικόνες responsive και όμορφες. Παράδειγμα: img-fluid για auto-scaling, rounded-circle για avatar style, float-start/end για στοίχιση εικόνων.

    Ειδοποίησης

    Χρησιμοποιούνται για μηνύματα ειδοποίησης (success, error, warning, info κλπ). Υποστηρίζουν χρώματα, dismissible κουμπί και animations (fade show). Πολύ χρήσιμα για feedback στον χρήστη.

    Badges

    Μικρές ετικέτες που εμφανίζονται δίπλα σε κείμενο ή κουμπιά. Συνήθως χρησιμοποιούνται για αριθμούς ειδοποιήσεων, status ή κατηγορίες. Μπορούν να πάρουν όλα τα theme colors και σχήματα όπως rounded-pill.
