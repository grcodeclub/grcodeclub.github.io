Διαχείριση αρχείων

Η PHP παρέχει πολλές συναρτήσεις για εργασία με αρχεία και φακέλους. Μπορείς να διαβάσεις, γράψεις, διαγράψεις, ελέγξεις και χειριστείς αρχεία εύκολα.

Άνοιγμα και Κλείσιμο Αρχείων

Για να ανοίξεις ένα αρχείο, χρησιμοποιείς την fopen(), και όταν τελειώσεις, το κλείνεις με fclose().

<?php
    $file = fopen("grcodeclub.txt", "r"); // Άνοιγμα αρχείου σε λειτουργία ανάγνωσης
    fclose($file); // Κλείσιμο του αρχείου
?>

Τρόποι ανοίγματος (mode)

rΆνοιγμα για ανάγνωση (το αρχείο πρέπει να υπάρχει)
wΆνοιγμα για εγγραφή (διαγράφει το υπάρχον περιεχόμενο ή δημιουργεί νέο αρχείο)
aΠροσθήκη στο τέλος του αρχείου
xΔημιουργία νέου αρχείου (αποτυγχάνει αν υπάρχει ήδη)
r+Ανάγνωση & εγγραφή (χωρίς να διαγράφει το αρχείο)

Ανάγνωση Αρχείων (fread(), fgets(), file_get_contents())

Ανάγνωση ολόκληρου του αρχείου

<?php
    $file = fopen("grcodeclub.txt", "r"); 
    $content = fread($file, filesize("grcodeclub.txt"));
    echo $content;
    fclose($file);
?>

Ανάγνωση γραμμή-γραμμή (fgets())

<?php
    $file = fopen("grcodeclub.txt", "r");
    while (!feof($file)) { // Διαβάζει μέχρι το τέλος του αρχείου
        echo fgets($file) . "
";
    }
    fclose($file);
?>

Ανάγνωση ολόκληρου του αρχείου με μία εντολή (file_get_contents())

<?php
    echo file_get_contents("grcodeclub.txt");
?>

Εγγραφή σε Αρχεία fwrite(), file_put_contents()

Γράψιμο στο αρχείο με fwrite()

<?php
    $file = fopen("grcodeclub.txt", "w"); // Άνοιγμα σε λειτουργία εγγραφής
    fwrite($file, "Γεια σου, κόσμε!\n");
    fwrite($file, "Αυτή είναι η δεύτερη γραμμή.");
    fclose($file);
?>

Γράψιμο εύκολα με file_put_contents()

<?php
    file_put_contents("grcodeclub.txt", "Αυτό είναι νέο περιεχόμενο!");
?>

Το file_put_contents() αντικαθιστά το περιεχόμενο. Αν θέλεις να προσθέσεις περιεχόμενο χωρίς να διαγράψεις το προηγούμενο, πρόσθεσε FILE_APPEND

<?php
    file_put_contents("grcodeclub.txt", "Νέα γραμμή\n", FILE_APPEND);
?>

        rmdir("new_folder"); // Ο φάκελος πρέπει να είναι άδειος

Χρήση του require() και include() για την εισαγωγή και εκτέλεση αρχείων στην PHP

το require(), το include() εισάγει και εκτελεί ένα εξωτερικό αρχείο PHP, αλλά η κύρια διαφορά είναι ότι αν το αρχείο δεν βρεθεί, το script συνεχίζει να εκτελείται και εμφανίζει μόνο μια προειδοποίηση (warning).

<?php
    include 'header.php'; // Εισάγουμε το αρχείο header.php
    echo "Η κύρια σελίδα.";
?>

Διαφορά μεταξύ include() και require():Το include() εμφανίζει μόνο προειδοποίηση αν το αρχείο δεν βρεθεί, ενώ το require() σταματά την εκτέλεση του script.

Χρήση του include_once() για την εισαγωγή αρχείων μία μόνο φορά στην PHP

Αυτές οι συναρτήσεις λειτουργούν με τον ίδιο τρόπο όπως το include() και το require(), αλλά με τη διαφορά ότι εξασφαλίζουν ότι το ίδιο αρχείο δεν θα περιληφθεί ξανά κατά την εκτέλεση του script.

  1. include_once(): Αν το αρχείο έχει ήδη περιληφθεί, δεν θα το περιλάβει ξανά.
  2. require_once(): Αν το αρχείο έχει ήδη περιληφθεί, δεν θα το περιλάβει ξανά (το ίδιο και για το require()).
<?php
    include_once 'header.php';  // Θα περιληφθεί μόνο μια φορά
    include_once 'header.php';  // Δεν θα περιληφθεί ξανά
?>

Χρήση της συνάρτησης file_exists() για έλεγχο ύπαρξης αρχείου ή φακέλου

<?php
    if (file_exists("example.txt")) {
        echo "Το αρχείο υπάρχει!";
    } else {
        echo "Το αρχείο δεν βρέθηκε!";
    }
?>

Χρήση της συνάρτησης is_file() ελέγχει αν το καθορισμένο path αναφέρεται σε ένα αρχείο.

<?php
    if (is_file("example.txt")) {
        echo "Αυτό είναι ένα αρχείο!";
    }
?>

Χρήση της συνάρτησης is_dir() ελέγχει αν το path αναφέρεται σε φάκελο (όχι αρχείο).

<?php
    if (is_dir("my_folder")) {
        echo "Αυτός είναι ένας φάκελος!";
    }
?>

Η συνάρτηση copy() αντιγράφει ένα αρχείο από μια τοποθεσία σε μια άλλη.

<?php
    copy("source.txt", "destination.txt");  // Αντιγράφει το αρχείο
?>

Η Η συνάρτηση chmod() αλλάζει τα δικαιώματα ενός αρχείου ή φακέλου.

<?php
    copy("source.txt", "destination.txt");  // Αντιγράφει το αρχείο
