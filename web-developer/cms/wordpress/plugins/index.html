WordPress Plugins

Το WordPress προσφέρει τη δυνατότητα να επεκτείνεις εύκολα τις δυνατότητες της ιστοσελίδας σου μέσω των plugins. Με αυτά μπορείς να προσθέσεις λειτουργίες όπως e-shop, φόρμες επικοινωνίας, βελτιστοποίηση SEO, ασφάλεια και πολλά άλλα, χωρίς να χρειάζεται να γράψεις κώδικα. Στον παρακάτω πίνακα θα βρεις συγκεντρωμένα μερικά από τα πιο χρήσιμα δωρεάν plugins (κατά τη γνώμη μου), χωρισμένα σε κατηγορίες, μαζί με σύντομη περιγραφή και τρόπους χρήσης.

Όλα τα πρόσθετα προέρχονται από το Επίσημο αποθετήριο του WordPress.
