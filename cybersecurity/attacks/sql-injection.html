SQL Injection

Οι επιθέσεις SQL Injection εκμεταλλεύονται μια ευπάθεια υπάρχουν σε εφαρμογές web, οι οποίες επικοινωνούν με server όπου αποθηκεύονται βάσεις δεδομένων.

Μια SQL επίθεση συμβαίνει όταν οι χάκερς πληκτρολογούν SQL κώδικα ερωτήματος σε μια φόρμα στο διαδίκτυο και η web εφαρμογή που επεξεργάζεται αυτόν τον κώδικα δεν τον ελέγχει σωστά και τον επικυρώνει (δηλ. τον “εκτελεί”), επιτρέποντας με αυτόν τον τρόπο τον εισβολέα να δώσει εντολές στη βάση δεδομένων για να διαρρεύσει αυτή τα δεδομένα της. Διαφορετικές εντολές παίρνουν διαφορετικά αποτελέσματα και συχνά ένας εισβολέας θα προσπαθήσει πολλές παραλλαγές για να δει τι θα του δώσει ως απάντηση μια βάση δεδομένων σε αυτές. Ένας εισβολέας, για παράδειγμα, μπορεί να στείλει ένα είδος εντολών SQL για να εμφανίσει όλα τα περιεχόμενα μιας βάσης δεδομένων στον browser του ή μπορεί να χρησιμοποιήσει άλλες εντολές για να εμφανίσει μέρη της βάσης δεδομένων ή για να αποκτήσει την δυνατότητα να προσθέσει, να τροποποιήσει ή να διαγράψει τα περιεχόμενα της βάσης δεδομένων.

SQL injection UNION attacks

Όταν ένα website είναι ευάλωτο σε SQL injection και τα αποτελέσματα του ερωτήματος επιστρέφονται στις απαντήσεις της εφαρμογής, μπορείτε να χρησιμοποιήσετε τη λέξη-κλειδί UNION για να ανακτήσετε δεδομένα από άλλους πίνακες στη βάση δεδομένων. Αυτό είναι κοινώς γνωστό ως επίθεση SQL injection UNION.

Προσδιορισμός του αριθμού των απαιτούμενων στηλών

1η Μέθοδος: Order/Group by

Για να προσδιορίσετε τον αριθμό των στηλών σε ένα ερώτημα, προσαρμόστε σταδιακά τον αριθμό που χρησιμοποιείται στις προτάσεις ORDER BY ή GROUP BY έως ότου ληφθεί μια ψευδής απάντηση. Παρά τις ξεχωριστές λειτουργίες των GROUP BY και ORDER BY εντός της SQL, και οι δύο μπορούν να χρησιμοποιηθούν με τον ίδιο τρόπο για τον προσδιορισμό του αριθμού στηλών του ερωτήματος.

1' ORDER BY 1--+    #True
1' ORDER BY 2--+    #True
1' ORDER BY 3--+    #True
1' ORDER BY 4--+    #False - Query is only using 3 columns

2η Μέθοδος: UNION SELECT

Η δεύτερη μέθοδος περιλαμβάνει την υποβολή μιας σειράς UNION SELECT payloads που καθορίζονται με διαφορετικό αριθμό null τιμών.

1' UNION SELECT null-- - Not working
1' UNION SELECT null,null-- - Not working
1' UNION SELECT null,null,null-- - Worked
