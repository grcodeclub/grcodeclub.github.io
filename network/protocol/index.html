Πρωτόκολλα

Τα πρωτόκολλα δικτύου (network protocols) είναι σύνολα κανόνων και προτύπων που καθορίζουν τον τρόπο με τον οποίο οι συσκευές επικοινωνούν μεταξύ τους σε ένα δίκτυο. Κάθε πρωτόκολλο ορίζει τις διαδικασίες για την αποστολή και λήψη δεδομένων, εξασφαλίζοντας την ομαλή και αποτελεσματική μεταφορά πληροφοριών.


ΚατηγορίαΌνομαΠλήρες ΌνομαΧρήση / Περιγραφή
IPv4 Internet Protocol v4 Χρησιμοποιείται για τη μεταφορά πακέτων στο Internet.
IPv6 Internet Protocol v6 Χρησιμοποιείται για τη μεταφορά πακέτων στο Internet.
ICMP Internet Control Message Protocol Χρησιμοποιείται για τη μεταφορά μηνυμάτων ελέγχου και σφαλμάτων στο Internet
ARP Address Resolution Protocol Χρησιμοποιείται για τη εντοπισμό μιας διεύθυνσης MAC με βάση την διεύθυνση IP
RARP Reverse Address Resolution Protocol Χρησιμοποιείται για την αντίστροφη μετατροπή μιας διεύθυνσης MAC σε αντίστοιχη διεύθυνση IP
NAT Network Address Translation Τεχνική που επιτρέπει σε πολλές συσκευές στο εσωτερικό ενός δικτύου να χρησιμοποιούν μια ενιαία δημόσια διεύθυνση IP.
FTP File Transfer Protocol Χρησιμοποιείται για τη μεταφορά αρχείων μεταξύ Server και Client στο Internet
SFTP SSH File Transfer Protocol Είναι ένα ασφαλές πρωτόκολλο μεταφοράς αρχείων που χρησιμοποιείται για την ασφαλή μεταφορά αρχείων μέσω δικτύου.
TFTPTrivial File Transfer Protocol Είναι πιο απλό από το FTP, κάνει τη μεταφορά αρχείων μεταξύ του client και του server, αλλά δεν παρέχει έλεγχο ταυτότητας χρήστη και άλλες χρήσιμες λειτουργίες που υποστηρίζονται από το FTP.
HTTP Hypertext Transfer Protocol Χρησιμοποιείται για τη μεταφορά website και data μεταξύ Server και Client
HTTPS Hypertext Transfer Protocol Secure Μια ασφαλής έκδοση του HTTP που χρησιμοποιεί κρυπτογράφηση.
SMTP Simple Mail Transfer Protocol Χρησιμοποιείται για την αποστολή και παράδοση μηνυμάτων στο ηλεκτρονικό ταχυδρομείο.
POP3 Post Office Protocol, version 3 Χρησιμοποιείται για τη λήψη ηλεκτρονικών μηνυμάτων από έναν Server.
IMAP Internet Message Access Protocol Ένα άλλο πρωτόκολλο για τη λήψη ηλεκτρονικών μηνυμάτων, με περισσότερες λειτουργίες από το POP3.
LPD Line Printer Daemon Έχει σχεδιαστεί για κοινή χρήση εκτυπωτή.
SNMP Simple Network Management Protocol
IRC Internet Relay Chat Είναι ένα σύστημα ανταλλαγής άμεσων μηνυμάτων/συνομιλίας που βασίζεται σε κείμενο.
MIME Multipurpose Internet Mail Extension Αυτό το πρωτόκολλο έχει σχεδιαστεί για να επεκτείνει τις δυνατότητες ενος υπάρχοντος πρωτοκόλλου ηλεκτρονικού ταχυδρομείου Διαδικτύου όπως το SMTP.
DNS Domain Name System Χρησιμοποιείται για τη μετάφραση των ονομάτων τομέων (domain names) σε διευθύνσεις IP.
DNSSEC DNS Security Extensions
BGP Border Gateway Protocol Ένα πρωτόκολλο δρομολόγησης που χρησιμοποιείται για την ανταλλαγή των path μεταξύ διαφορετικών αυτόνομων συστημάτων (AS)
RIP Routing Information Protocol Πρωτόκολλο δρομολόγησης που χρησιμοποιείται για την ανταλλαγή πληροφοριών δρομολόγησης μεταξύ router
OSPF Open Shortest Path First Πρωτόκολλο δρομολόγησης που χρησιμοποιείται για τον υπολογισμό της βέλτιστης διαδρομής σε μεγάλα δίκτυα
IGRP Interior Gateway Routing Protocol
EIGRP Enhanced Interior Gateway Routing Protocol
EGP Exterior Gateway Protocol
IS-IS Immediate system-to-immediate system
