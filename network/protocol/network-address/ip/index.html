IP

Η IP (Internet Protocol) είναι μια μοναδική διεύθυνση που χρησιμοποιείται για να αναγνωρίζεται μια συσκευή σε ένα δίκτυο, όπως το Διαδίκτυο. Η IP διεύθυνση επιτρέπει την επικοινωνία μεταξύ συσκευών μέσω της αποστολής και λήψης δεδομένων.

Εκδόσεις του IP

  • IPv4: Η παλαιότερη και πιο διαδεδομένη έκδοση. Χρησιμοποιεί διευθύνσεις 32-bit (π.χ. 192.168.1.1).
  • IPv6: Η νεότερη έκδοση, σχεδιασμένη για να καλύψει την αυξανόμενη ανάγκη σε διευθύνσεις. Χρησιμοποιεί 128-bit διευθύνσεις
