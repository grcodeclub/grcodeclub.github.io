IMAP
(Internet Message Access Protocol)

Είναι ένα πρωτόκολλο πρόσβασης ηλεκτρονικού ταχυδρομείου, παρόμοιο με το POP3, που επιτρέπει σε έναν client να λαμβάνει μηνύματα από έναν server. Ωστόσο, το IMAP προσφέρει περισσότερες δυνατότητες, καθώς σχεδιάστηκε για να διατηρεί τα emails στον server, αντί να τα κατεβάζει μόνιμα στον υπολογιστή του client. Αυτό σημαίνει ότι απαιτεί περισσότερο χώρο στο δίσκο και περισσότερους πόρους CPU στον διακομιστή.
Το IMAP συνήθως χρησιμοποιεί την TCP θύρα 143 ή τη θύρα 993 για ασφαλή, κρυπτογραφημένη επικοινωνία μέσω SSL.
