Email

IMAP
(Internet Message Access Protocol)

Είναι ένα πρωτόκολλο πρόσβασης ηλεκτρονικού ταχυδρομείου, παρόμοιο με το POP3, που επιτρέπει σε έναν client να λαμβάνει μηνύματα από έναν server. Ωστόσο, το IMAP προσφέρει περισσότερες δυνατότητες, καθώς σχεδιάστηκε για να διατηρεί τα emails στον server, αντί να τα κατεβάζει μόνιμα στον υπολογιστή του client. Αυτό σημαίνει ότι απαιτεί περισσότερο χώρο στο δίσκο και περισσότερους πόρους CPU στον διακομιστή.
Το IMAP συνήθως χρησιμοποιεί την TCP θύρα 143 ή τη θύρα 993 για ασφαλή, κρυπτογραφημένη επικοινωνία μέσω SSL.

SMTP
(Simple Mail Transfer Protocol)

Το SMTP είναι το πρωτόκολλο που χρησιμοποιείται για την αποστολή ηλεκτρονικών μηνυμάτων. Χρησιμοποιείται όταν ένας client ηλεκτρονικού ταχυδρομείου ( π.χ το Outlook), στέλνει ένα μήνυμα σε έναν server ηλεκτρονικού ταχυδρομείου, αλλά και όταν ένας server στέλνει μήνυμα σε άλλο server.

Το SMTP είναι υπεύθυνο για τη μεταφορά των μηνυμάτων, αλλά όχι για την ανάγνωση ή την αποθήκευσή τους. Για ασφαλή μεταφορά των δεδομένων, το SMTP μπορεί να χρησιμοποιεί διάφορες θύρες: την TCP θύρα 25 για την παραδοσιακή επικοινωνία, τη θύρα 465 για κρυπτογραφημένη σύνδεση μέσω SSL και τη θύρα 587 για ασφαλή αποστολή με TLS.

POP3
(Post Office Protocol version 3)

Το POP3 είναι ένα πρωτόκολλο ηλεκτρονικού ταχυδρομείου που επιτρέπει σε έναν client να «κατεβάσει» μηνύματα από έναν server ηλεκτρονικού ταχυδρομείου στον τοπικό υπολογιστή του user. Το POP3 είναι απλό και σχεδιασμένο κυρίως για τη λήψη μηνυμάτων, χωρίς πολλές επιπλέον δυνατότητες.

O client συνδέεται με τον server, κατεβάζει όλα τα διαθέσιμα μηνύματα, τα διαγράφει από τον server και στη συνέχεια αποσυνδέεται. Ωστόσο, τα περισσότερα σύγχρονα προγράμματα προσφέρουν τη δυνατότητα να διατηρηθεί ένα αντίγραφο των μηνυμάτων στο server, αν ο χρήστης το επιλέξει.

Το POP3 είναι λιγότερο απαιτητικό σε πόρους από το IMAP, αφού τα μηνύματα αποθηκεύονται κυρίως τοπικά και δεν απαιτείται συνεχής επικοινωνία με τον server. Συνήθως χρησιμοποιεί την TCP θύρα 110 για μη κρυπτογραφημένες συνδέσεις ή τη θύρα 995 για ασφαλή επικοινωνία μέσω SSL/TLS.
