Roadmap

  • Τι είναι το δίκτυο υπολογιστών και ποια είναι η σημασία του.
  • Είδη δικτύων: LAN, WAN, MAN, PAN.
  • Τυπολογίες δικτύων (Bus, Star, Ring, Mesh, Hybrid).
  • Βασικός εξοπλισμός δικτύων: Router, Switch, Hub, Modem.
  • Αρχιτεκτονική Client-Server.
  • Τι είναι το πρωτόκολλο και η σημασία του.

  • Κατανόηση του OSI μοντέλου (7 επίπεδα)
  • Μοντέλο TCP/IP (4 επίπεδα)
  • Βασικές διαφορές μεταξύ OSI και TCP/IP μοντέλων
  • Ενθυλάκωση / Αποθυλάκωση

  • Ethernet
  • MAC
  • Wi-Fi Standards (802.11)

  • Είδη IP Διευθύνσεων (IPv4 και IPv6
  • Επικεφαλίδες IPv4 και IPv6
  • Κατηγορίες Διευθύνσεων IPv4 (Δημόσιες και Ιδιωτικές)
  • Class
  • IP Subnetting: Πρακτικές εφαρμογές και υπολογισμοί με τη χρήση subnet masks και CIDR (Classless Inter-Domain Routing).
  • NAT: Πώς λειτουργεί το NAT και γιατί είναι απαραίτητο
  • DCHP: Discover, Offer, Request και Acknowledgment
  • Unicast, Multicasting και Broadcasting
  • Πρωτόκολλα δρομολόγησης

  • Βασικά Χαρακτηριστικά του TCP
  • Δομή TCP Segment (Header και Data)
  • 3-Way Handshake
  • Βασικά Χαρακτηριστικά του UDP
  • Δομή UDP Datagram (Header και Data)
  • Χρήσεις του UDP
  • Διαφορές TCP και UDP
  • Windowing και Flow Control: Πώς το TCP διαχειρίζεται τη ροή δεδομένων και τη συμφόρηση.

  • Πρωτόκολλα
  • Πολυπλεξία (multiplexing)

  • DNS
  • Proxy

  • TLS/SSL
  • Firewalls και IDS/IPS
  • VPN και IPsec
  • Wi-Fi Security

  • Βασικές Έννοιες Κινητών Δικτύων (Πρωτόκολλα κινητής επικοινωνίας, Κυψελωτά δίκτυα, Frequencies)
  • Τεχνολογίες Κινητών Δικτύων (1G έως 5G)
  • Τεχνολογία LTE (Long-Term Evolution): OFDM,MIMO,VoLTE
  • Αρχιτεκτονική Κινητών Δικτύων: Mobile Core Network (EPC, 5GC), RAN (Radio Access Network), Τοπική και Παγκόσμια Περιήγηση (Roaming)
  • Ασφάλεια Κινητών Δικτύων: Αυθεντικοποίηση και Κρυπτογράφηση, Ασφάλεια στο 5G, IMSI Catchers
