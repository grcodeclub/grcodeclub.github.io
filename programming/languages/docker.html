Docker

Το Docker είναι μια πλατφόρμα ανοικτού κώδικα που χρησιμοποιείται για την αυτοματοποίηση, την ανάπτυξη και την εκτέλεση εφαρμογών μέσα σε περιβάλλοντα περιορισμένων πόρων, γνωστά ως "containers".

Η λογική του Docker, είναι ότι σηκώνουμε ένα container για κάθε service που θέλουμε.

Docker Image

Το Docker Image αποτελεί ένα αρχείο που περιλαμβάνει τις απαραίτητες οδηγίες για τη δημιουργία ενός container.

Βασικές εντολές διαχείρισης image

Για να δούμε τώρα πόσα image βρίσκονται στον υπολογιστή μας.

docker images
REPOSITORY              TAG                 IMAGE ID            CREATED             SIZE
hello-world             latest              bf756fb1ae65        4 months ago        13.3kB

Για να κατεβάσουμε λοιπόν ένα image (π.χ. ubuntu)

docker pull ubuntu:20.04

Για να διαγράψουμε ένα image με βάση το ID 

docker rmi bf756fb1ae65

Αν υπάρχουν περισσότερα από ένα image με το ίδιο ID έχουμε στο σύστημά.

docker rmi -f bf756fb1ae65

Για να διαγράψουμε τέλος όλα τα αχρησιμοποίητα image.

docker image prune

Container

Ένα Docker Container χρησιμοποιεί το λειτουργικό και τον πυρήνα του host καθως δεν έχει δικό του πυρήνα. Με αποτέλεσμα να είναι πολύ ποιο ελαφρύ και να ξοδεύει μόνο τα αναγκαία resources, για να τρέξουν τα services που θέλει.
Κάθε container είναι πλήρως απομονωμένο από το host λειτουργικό και από άλλα containers.
Κάθε container δεν κρατάει δεδομένα μέσα του. Δηλαδή αν τρέχουμε ένα container με mySQL, τα δεδομένα της βάσης θα χαθούν αν κάνουμε restart

Βασικές εντολές διαχείρισης container

Για να δούμε λοιπόν μία γενική εικόνα των container που έχουμε στο σύστημά μας, δίνουμε την εντολή:

docker ps -a
CONTAINER ID    IMAGE              COMMAND            CREATED         STATUS          PORTS                NAMES
8b3a2f0d4e25    nginx:latest       "nginx -g 'daemon   2 hours ago     Up 2 hours      0.0.0.0:80->80/tcp   apache
  • CONTAINER ID: Ο αριθμός του κάθε container στο σύστημά μας.
  • IMAGE: Η υπηρεσία που τρέχει το κάθε container.
  • CREATED: Πότε δημιουργήθηκε το container.
  • STATUS: Εδώ μπορούμε να δούμε αν το container λειτουργεί ή αν είναι σταματημένο.
  • PORTS: Εδώ προβάλλονται τα port στα οποία τρέχει το κάθε container.
  • NAMES: Εδώ είναι τα ονόματα που τους έχουμε δώσει.

Να σταματήσουμε ένα container (π.χ apache).

docker stop apache

Να ξεκινήσουμε ένα container (π.χ apache)

docker start apache

Για να αφαιρέσουμε ένα container (π.χ apache) από το σύστημά μας θα πρέπει πρώτα να το σταματήσουμε και μετά να το διαγράψουμε.

docker rm -f apache

Για να διαγράψουμε μαζικά όλα τα container που έχουμε σταματημένα δίνουμε την εντολή

docker container prune

Να μας εμφανίσιμή την port για ένα συγκεκριμένο container (π.χ apache). 

docker port apache

Βασικές εντολές διαχείρισης Network

Το Docker δημιουργεί αυτόματα ένα bridge δίκτυο, το οποίο ονομάζεται "docker0" και μπορούμε να το δούμε δίνοντας στο τερματικό μας την εντολή:

ifconfig

Για να φτιάξουμε τώρα το δικό μας bridge network με όνομα "gr-code" θα δώσουμε την εντολή:

docker network create -d bridge gr-code

Για να φτιάξουμε ένα overlay network με την ίδια ονομασία θα δώσουμε την εντολή:

docker network create -d overlay gr-code

Για να δούμε λοιπόν μία λίστα των δικτύων μας θα δώσουμε την εντολή:

docker network ls
NETWORK ID          NAME                DRIVER              SCOPE
c1ae8a3bd6fb        bridge              bridge              local
134626deef16        host                host                local
7c00c10a741a        none                null                local
  • NETWORK ID: Ο αριθμός του δικτύου.
  • NAME: Το όνομα που έχουμε ορίσει στο δίκτυο.
  • DRIVER: Ο driver μέσω του οποίου τρέχει το δίκτυό μας.
  • SCOPE: Εδώ θα δούμε αν το δίκτυό μας είναι local ή αν εξυπηρετεί κάποιο cluster με Docker Swarm.

Docker Volumes

Τα volumes είναι ο προτιμώμενος τρόπος αποθήκευσης δεδομένων στο Docker, έξω από το lifecycle του container (ώστε να μην χαθούν όταν το container διαγραφεί).

Δημιουργία Volume

docker volume create my_volume

Λίστα με όλα τα Volumes

docker volume ls

Πληροφορίες για Volume

docker volume inspect my_volume

Διαγραφή Volume

docker volume rm my_volume

Διαγραφή όλων των αχρησιμοποίητων Volumes

docker volume prune

Πού αποθηκεύονται τα Volumes στον δίσκο;

Συνήθως: /var/lib/docker/volumes/

Docker Compose

Το Docker Compose είναι ένα εργαλείο που σε βοηθάει να ξεκινάς πολλά containers μαζί με μία μόνο εντολή, χρησιμοποιώντας ένα αρχείο ρυθμίσεων σε μορφή YAML (συνήθως docker-compose.yml).

ΕντολήΠεριγραφή
docker-compose upΕκκινεί όλα τα services
docker-compose up -dΕκκινεί στο background (detached mode)
docker-compose downΣταματάει και διαγράφει containers/networks
docker-compose logsΔείχνει logs όλων των services
docker-compose execΕκτελεί εντολή μέσα σε running container
docker-compose buildΚάνει build εικόνων από Dockerfile

Αν θελουμε ενα συγκεκριμενο service - container βαζουμε στο τελος το ονομα του.

Docker Swarm

Το Docker Swarm σού επιτρέπει να τρέχεις containers σε πολλά μηχανήματα.

  • Δημιουργεί "services" αντί για μεμονωμένα containers.
  • Διαχειρίζεται πολλά machines (nodes) σαν ένα σύστημα.
  • Αναπαράγει containers (replicas) για μεγαλύτερη διαθεσιμότητα.
  • Αν πέσει ένα node, μεταφέρει τα containers αλλού.
  • Μοιράζει το traffic αυτόματα στα replicas.

Ρόλοι στο Swarm:

  • Manager : Διαχειρίζεται το cluster, αποφασίζει
  • Worker : Τρέχει containers, εκτελεί tasks

Ενεργοποίηση Swarm Mode

  1. Μετατρέπει το host σε Swarm manager.
  2. Εμφανίζει ένα join-token για να προσθέσεις worker nodes.
docker swarm init

Για συγκεκριμένη IP:

docker swarm init --advertise-addr <IP>

Αποχώρηση από το υπάρχον Swarm

Αν ο node είναι worker, τρέξε:

ddocker swarm leave

Αν ο node είναι manager, τρέξε:

docker swarm leave --force

⚠️ Αν είναι ο ΜΟΝΑΔΙΚΟΣ manager του swarm, η εντολή θα τερματίσει το cluster.

Έλεγχος κατάστασης swarm

docker node ls

Προσθήκη Worker / Manager Node

docker swarm join --token <TOKEN> <MANAGER-IP>:2377

Ενημέρωση ενός service

docker service update --image nginx:alpine web
  • Κάνει rolling update σε όλα τα replicas.

Services

Αν θέλουμε να εμφανίσουμε μια λίστα με όλες τις υπηρεσίες που εκτελούνται.

docker service ls

Δείχνει πού και πώς τρέχουν τα containers του service

docker service ps onoma_service

Δείχνει τα logs ενός Docker Service που τρέχει σε περιβάλλον Docker Swarm με το όνομα onoma_service.

docker service log onoma_service

Επαναδημιουργεί όλα τα tasks

docker service update --force onoma_service=n

Κάνει ενημέρωση (update) μιας Docker Swarm υπηρεσίας,ώστε τα tasks της υπηρεσίας να τρέχουν μόνο σε έναν συγκεκριμένο node, με hostname snf-79675.

docker service update --constraint-add 'node.hostname == snf-79675' onoma_service

Αλλάζει τον αριθμό replicas

docker service scale onoma_service=n

Διαγράφει service

docker service rm onoma_service

Προβολή λεπτομερειών για ένα service

docker service inspect onoma_service

Επιστρέφει το service στην προηγούμενη έκδοση

docker service rollback onoma_service

Ζωντανά logs (follow mode)

docker service logs -f onoma_service

Node

Ένα node είναι ένα μηχάνημα (server ή VM) που συμμετέχει σε ένα Swarm cluster.

Χρησιμοποιείται στο Docker Swarm mode και εμφανίζει μια λίστα με όλους τους nodes (μηχανές) που συμμετέχουν στο Swarm Cluster.

docker node ls
ID                            HOSTNAME    STATUS    AVAILABILITY   MANAGER STATUS   ENGINE VERSION
m5kz8zq9abcde1n4yz45ty98      node1       Ready     Active         Leader           25.0.2
qwe890vbn567zxc234asd789      node2       Ready     Active                          25.0.2
fgh123rty456bnm890lkj123      node3       Ready     Active                          25.0.2

Εμφανίζει λεπτομερείς πληροφορίες για το συγκεκριμένο node snf-80512 στο Docker Swarm cluster, σε μορφή JSON.

docker node inspect snf-80512

Δείχνει τα tasks που τρέχουν στο συγκεκριμένο node

docker node ps onoma_node

Ενημερώνει χαρακτηριστικά node

docker node update

Προάγει node σε manager

docker node promote onoma_node

Υποβαθμίζει node σε worker

docker node demote onoma_node

Αφαιρεί node από το swarm

docker node rm onoma_node

Αλλάζει το availability (active / pause / drain)

docker node update --availability

Docker Config

Το docker config επιτρέπει να :

  1. Ανεβάζεις αρχεία ρυθμίσεων (π.χ. Nginx, app settings) στο Swarm
  2. Τα μοιράζεσαι σε services, χωρίς να τα "χώνεις" μέσα στο image
  3. Είναι ασφαλής και εύκολος τρόπος να διαχειρίζεσαι αρχεία ρυθμίσεων σε περιβάλλον production
docker config create nginx_config ./nginx.conf

docker-compose.yml

services:
  web:
    image: nginx:latest
    ports:
      - "80:80"
    configs:
      - source: nginx_config
        target: /etc/nginx/nginx.conf

Docker Stack

Ένα stack είναι ένας "ομάδα" από services που δουλεύουν μαζί (π.χ. database), και το docker stack τα εκκινεί, ενημερώνει και διαχειρίζεται όλα μαζί με ένα αρχείο YAML.

Κάνει deploy όλο το stack

docker stack deploy -c docker-compose.yml mystack

Δείχνει όλα τα stacks

docker stack ls

Δείχνει τα services του stack

docker stack services mystack

Δείχνει πού και πώς τρέχουν τα containers

docker stack ps mystack

Σβήνει το stack και όλα τα services του stack

docker stack rm mystack
