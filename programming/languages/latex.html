LaTeX

Το LaTeX είναι ένα σύστημα στοιχειοθεσίας εγγράφων που χρησιμοποιείται ευρέως για τη συγγραφή επιστημονικών και τεχνικών κειμένων. Πρόκειται για μια γλώσσα μορφοποίησης κειμένου.

Χαρακτηριστικά του LaTeX

  1. Ακαδημαϊκή χρήση: Ιδανικό για έγγραφα με μαθηματικούς τύπους, επιστημονικές εργασίες, διατριβές, βιβλία κ.λπ.
  2. Αυτόματη μορφοποίηση: Διαχειρίζεται αυτόματα τη διάταξη του κειμένου, τις βιβλιογραφικές αναφορές, την αρίθμηση κεφαλαίων και εικόνων.
  3. Επαγγελματική τυπογραφία: Παρέχει εξαιρετική ποιότητα εκτύπωσης.
  4. Υποστήριξη μαθηματικών τύπων: Μπορείς να γράψεις περίπλοκες εξισώσεις με ακρίβεια.
  5. Διαχωρισμός περιεχομένου από μορφοποίηση: Εστιάζεις στο περιεχόμενο χωρίς να ανησυχείς για το στυλ.

Βασική Δομή Ενός Εγγράφου LaTeX

\documentclass{article}  % Ορίζει τον τύπο του εγγράφου
\usepackage{amsmath}      % Ενεργοποιεί μαθηματικά πακέτα

\begin{document}          % Έναρξη του εγγράφου

\title{Εισαγωγή στο LaTeX}
\author{Το Όνομά σου}
\date{\today}
\maketitle

\section{Εισαγωγή}
Αυτό είναι ένα παράδειγμα εγγράφου στο LaTeX.

\section{Μαθηματικά}
Μια εξίσωση:
\begin{equation}
    E = mc^2
\end{equation}

\end{document}

\begin{thebibliography}{9}

\bibitem{latexcompanion}
Leslie Lamport, \textit{LaTeX: A Document Preparation System}, Addison-Wesley, 1986.

\end{thebibliography}

Διαχείριση Παραπομπών και Αναφορών

Το LaTeX υποστηρίζει αναφορές μέσα στο κείμενο και αυτόματη δημιουργία βιβλιογραφίας χρησιμοποιώντας BibTeX:

\cite{latexcompanion}

Ένα παράδειγμα αρχείου .bib για χρήση με BibTeX:

@book{latexcompanion,
  author    = {Leslie Lamport},
  title     = {LaTeX: A Document Preparation System},
  publisher = {Addison-Wesley},
  year      = {1986}

Στη συνέχεια, στο αρχείο .tex, προσθέτουμε:

\bibliographystyle{plain}
\bibliography{mybibliography}
