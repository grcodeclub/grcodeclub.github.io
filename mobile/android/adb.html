Android Debug Bridge

Το adb (Android Debug Bridge) είναι ένα εργαλείο γραμμής εντολών που επιτρέπει τη σύνδεση και διαχείριση Android συσκευών μέσω του υπολογιστή. Παρέχει δυνατότητες όπως απομακρυσμένος έλεγχος της συσκευής, εγκατάσταση εφαρμογών, μεταφορά αρχείων, εκτέλεση εντολών στο shell της συσκευής, και αντιμετώπιση προβλημάτων. Χρησιμοποιείται κυρίως από προγραμματιστές και τεχνικούς για debugging, testing, και άλλες λειτουργίες συντήρησης των Android συσκευών.

Εμφανίζει τις συσκευές που είναι συνδεδεμένες μέσω USB.

adb devices

Εγκαθιστά ένα αρχείο APK στη συσκευή.

adb install myapp.apk

Επανεκκίνηση συσκευής

adb reboot

Αντιγραφή αρχείου από τον υπολογιστή στη συσκευή

adb push myfile.txt /sdcard/

Άνοιγμα shell στη συσκευή

adb shell

Λήψη στιγμιότυπου οθόνης

adb shell screencap /sdcard/screenshot.png
adb pull /sdcard/screenshot.png

Καταγραφή οθόνης (screen recording)

adb shell screenrecord /sdcard/record.mp4

Επανεκκίνηση σε recovery mode

adb reboot recovery

Αντιγραφή αρχείου από τη συσκευή στον υπολογιστή

adb pull /sdcard/myfile.txt

Εκτέλεση εφαρμογής

adb shell am start -n com.example/.MainActivity
