Οδηγός Αγοράς Κινητού

🔋 Μπαταρία

  1. Χωρητικότητα (mAh): όσο μεγαλύτερη τόσο καλύτερη (4.500–5.500 mAh είναι στάνταρ σήμερα)
  2. Γρήγορη φόρτιση: 30W–120W (όσο μεγαλύτερο, τόσο πιο γρήγορη φόρτιση)
  3. Ασύρματη φόρτιση: 10W–50W
  4. Reverse wireless charging: να φορτίζεις άλλα devices (π.χ. ακουστικά)

⚡ Επεξεργαστής

  1. CPU: Πυρήνες. Όσο νεότερη γενιά → καλύτερη απόδοση & εξοικονόμηση ενέργειας
  2. GPU
  3. Ασύρματη φόρτιση: 10W–50W
  4. Reverse wireless charging: να φορτίζεις άλλα devices (π.χ. ακουστικά)

🖥️ Οθόνη

  1. Μέγεθος: 6.1–6.7” είναι συνηθισμένο
  2. LCD → οικονομικά μοντέλα
  3. Τεχνολογία:
    • LCD → οικονομικά μοντέλα
    • AMOLED / OLED → καλύτερα χρώματα, μαύρα, κατανάλωση
    • LTPO OLED → δυναμικό refresh rate, καλύτερη μπαταρία
  4. Ρυθμός ανανέωσης: 60Hz (basic), 90Hz/120Hz (ομαλή κίνηση), 144Hz+ (gaming)
  5. Φωτεινότητα (nits): 800–2000 nits για ήλιο
  6. HDR υποστήριξη: HDR10, HDR10+, Dolby Vision

📸 Κάμερες

  1. Κύριος αισθητήρας (Wide): Μεγάλα pixels (1.0μm–1.4μm), χαμηλό f/1.8 → καλύτερο φως
  2. Megapixels: Δεν είναι το μόνο κριτήριο (50MP με καλή επεξεργασία μπορεί να είναι καλύτερη από 108MP κακή)
  3. OIS (Optical Image Stabilization): σταθερές φωτογραφίες/βίντεο
  4. Selfie κάμερα: 8–32MP, autofocus είναι μεγάλο συν
  5. Βίντεο:
    • 4K 30/60fps → στάνταρ στα mid-range
    • 8K → μόνο σε high-end
    • Slow motion (240fps–960fps)

💾 Μνήμη & Αποθήκευση

  1. RAM:
    • 4GB → ελάχιστο για basic χρήση
    • 6–8GB → ιδανικό mid-range
    • 12–16GB → high-end, multitasking, gaming
  2. Αποθηκευτικός χώρος
    • 64GB → πλέον μικρό
    • 128GB → ελάχιστο στάνταρ
    • 256GB/512GB → high-end
    • Επέκταση με microSD: Σπάνια στα νέα μοντέλα, καλό bonus.

📡 Συνδεσιμότητα

  1. Δίκτυα: 4G LTE, 5G (SA/NSA)
  2. Wi-Fi
  3. Bluetooth: v5.0–5.4 (όσο πιο νέο → καλύτερο range/χαμηλότερη κατανάλωση)
  4. NFC: για ανέπαφες πληρωμές

🖥️ Οθόνη

  1. Αισθητήρας δακτυλικού αποτυπώματος
  2. Face Unlock

🔊 Ήχος & Multimedia

  1. Ηχεία: Stereo > Mono
  2. Dolby Atmos / Hi-Res Audio: για καλύτερο ήχο.
